Step-by-step guide

How to Use VidLoom

Learn how to paste a public link, inspect available media, choose a format and download compatible public files with VidLoom.

1. Find a public media page

Open the video or audio page in your browser. Make sure the page is publicly accessible without attempting to bypass any login or privacy restriction.

2. Copy the complete URL

Use the address bar or the platform's share feature. Copy the complete public URL so the website can identify the source correctly.

3. Paste the link

Return to VidLoom, paste the URL into the Source URL field and select Fetch media. Wait for the title and available information to appear.

4. Choose format and quality

Select Video for MP4 processing or Audio for MP3 processing where available. Source platforms do not always provide every resolution or codec.

5. Start and monitor

Start the download and use the progress controls. Network interruptions, unavailable formats or source-side restrictions can cause a job to stop.

Use responsibly

Only download content when you have the right or permission to do so. Copyright and platform rules remain the responsibility of the user.
